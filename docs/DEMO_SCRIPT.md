# Demo 视频讲解词

大家好，我展示的作品是“章幕”，一款面向小说作者的 AI 小说转剧本工具。首先在左侧输入作品名称、选择短剧、电影、电视剧或舞台剧形式，并粘贴至少三个章节，系统会校验章节数量；右上角可以选择 DeepSeek、GLM、通义千问等模型，填写 API Key 后测试连接和响应速度。点击“开始改编”后，系统按照故事圣经、全书改编蓝图、分章动作对白和 YAML 校验多个阶段渐进生成，完成一部分就立即展示，作者不必等待全部结束。故事圣经统一管理人物、地点和关键道具，场景拆解展示每场的内外景、时间、戏剧功能、动作、对白、说话人、制作提示和原文依据；剧本诊断会给出完整度、预计时长、对白与动作占比、原文可信度，并定位缺少地点、动作、说话人或原文证据的场景。作者可以进入结构编辑器，新增或修改人物、地点、道具、场景和每一个 Beat，修改后由 Java 后端重新编号并执行跨引用语义校验。最终结果可在 YAML 标签中查看并下载，内容包含项目元数据、稳定 ID 的故事资产、场景、动作对白、连续性、原文忠实度和改编说明；配套 JSON Schema 与设计文档可以继续用于编辑器、CI 或其他创作工具校验。整个流程实现了从三章以上小说文本到可编辑、可追溯、可进一步打磨的结构化剧本初稿。
